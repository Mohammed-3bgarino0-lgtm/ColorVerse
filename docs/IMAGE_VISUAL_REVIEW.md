# مراجعة الصور واعتمادها — ColorVerse

الفرع: `feature/story-studio-integration`

آخر تحديث: 26 يوليو 2026

## الهدف

لا تُرسل الصور مباشرة إلى PDF النهائي بعد التوليد. تمر أولًا عبر بوابة مراجعة بصرية مستقلة تتحقق من:

- ثبات شخصية البطل.
- مناسبة الغلاف لعالم القصة.
- ملاءمة كل صورة ملونة لنص المشهد وعمر الطفل.
- خلو صفحة التلوين من النصوص والأرقام.
- تطابق صفحة التلوين مع الصورة الملونة في الشخصيات والوضعية والعناصر الأساسية.

## الصفحة

```text
image-review.html
```

تقرأ الصفحة مسودة الكتاب من:

```text
colorverse-book-draft-v3
```

وتعرض:

1. مرجع شخصية البطل.
2. الغلاف.
3. صورة القصة الملونة لكل مشهد.
4. صفحة التلوين المطابقة بجانبها.
5. موافقة مستقلة لكل أصل.
6. تأكيد تطابق مستقل لكل زوج صور.
7. ملاحظات اختيارية للبطل والغلاف وكل مشهد.

## حالة المراجعة

تُحفظ داخل المسودة:

```json
{
  "imageReview": {
    "version": 1,
    "approved": false,
    "approvedAt": null,
    "hero": { "approved": false, "note": "" },
    "cover": { "approved": false, "note": "" },
    "scenes": {
      "1": {
        "storyApproved": false,
        "coloringApproved": false,
        "pairMatched": false,
        "note": ""
      }
    }
  }
}
```

لا يتحول `approved` إلى `true` إلا عندما:

- يُعتمد البطل.
- يُعتمد الغلاف.
- تُعتمد صورة القصة لكل مشهد.
- تُعتمد صفحة التلوين لكل مشهد.
- يؤكد المراجع تطابق كل زوج.
- تكون جميع الأصول `productionReady: true`.

## إعادة توليد أصل واحد

```http
POST /api/story-images/regenerate
```

الأنواع:

```text
hero
cover
story + sceneNumber
coloring + sceneNumber
```

### المراجع المستخدمة

- البطل: بيانات الطفل وصورته عند وجود الإذن.
- الغلاف: مرجع البطل الحالي.
- صورة المشهد: مرجع البطل الحالي.
- صفحة التلوين: صورة المشهد الملونة الحالية.

### إلغاء الموافقات المتأثرة

| الأصل المعاد | الموافقات التي تُلغى |
|---|---|
| البطل | البطل، الغلاف، جميع صور القصة، جميع صفحات التلوين والتطابق |
| الغلاف | الغلاف فقط |
| صورة قصة | صورة القصة وصفحة التلوين والتطابق للمشهد نفسه |
| صفحة تلوين | صفحة التلوين والتطابق للمشهد نفسه |

لا تُحذف الأصول القديمة من Drive في هذه المرحلة؛ يحتفظ بها Drive كسجل إنتاج، ويستخدم الكتاب رابط الأصل الأحدث الموجود في المسودة.

## حماية الملفات

عند استخدام Google Drive، لا تقرأ خدمة إعادة التوليد أي ملف إلا إذا:

- كان `storagePath` يبدأ بـ `drive:`.
- كان الملف داخل مجلد `03_أصول_الصور` المعتمد.
- كان نوع MIME صورة.

المجلد المعتمد:

```text
1FHD5BQAixH2cIhlsIC54uBI-aLYwy0vm
```

الملفات المحلية محصورة داخل `GENERATED_ASSET_DIR` ويُرفض أي مسار يحاول الخروج منه.

## بوابة PDF وDrive

يحمل قالب PDF:

```text
public/js/book-image-review-gate-runtime.js
```

ويُعطّل:

- الطباعة النهائية.
- PDF النهائي.
- الحفظ النهائي في Drive.

حتى وجود:

```text
imageReview.approved = true
imageReview.approvedAt = ISO timestamp
```

كما يطلب خادم Drive الرأس:

```http
X-ColorVerse-Image-Approved: true
```

عند رفع أي PDF نهائي.

## حدود الاستخدام


الحد منفصل عن مهمة إنتاج الكتاب الكامل.

## فحوص الجودة

```bash
npm run validate:image-review
npm run test:image-regeneration
npm run quality:stories
```

الاختبار الوهمي لا يتصل بـGemini، ويختبر:

- إنتاج الكتاب الأولي في تخزين مؤقت.
- إعادة صورة مشهد واحدة.
- إعادة صفحة تلوين واحدة من الصورة الملونة الجديدة.
- إعادة البطل.
- قائمة الموافقات التي يجب إلغاؤها في كل حالة.
