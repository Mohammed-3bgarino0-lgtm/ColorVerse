# مراجعة جاهزية النظام ودورة الكتاب الكاملة

الفرع: `feature/story-studio-integration`

آخر تحديث: 26 يوليو 2026

## هدف المرحلة

منع بدء تجربة إنتاجية قبل التأكد من أن محرك القصص ومحرك الصور وGoogle Drive وبوابات المراجعة تعمل وفق شروط واحدة.

## لوحة الجاهزية

الصفحة:

```text
system-readiness.html
```

تقرأ:

```http
GET /api/system/readiness
POST /api/system/verify-drive
```

وتعرض حالة:

- خادم Node 20 أو أحدث.
- مفتاح Gemini على الخادم.
- نموذج كتابة القصص.
- نموذج إنتاج الصور.
- حساب خدمة Google Drive.
- فهرس المراجع.
- مجلد نسخة القصة.
- مجلد نسخة التلوين.
- مجلد أصول الصور.
- مجلد البيانات والفهارس.

لا تعرض اللوحة المفاتيح أو المفتاح الخاص أو محتوى بيانات الاعتماد.

## معيار الجاهزية الموحد

الملف:

```text
src/lib/book-production-readiness.ts
```

لا تعتبر نسخة الكتاب جاهزة إلا عند تحقق:

1. موافقة ولي الأمر على النص.
2. اعتماد المراجعة البصرية.
3. عدد المشاهد 8 أو 12 أو 16 ومطابق لإعداد الكتاب.
4. جاهزية صورة البطل.
5. جاهزية الغلاف.
6. اكتمال جميع صور القصة للنسخة الملونة.
7. اكتمال جميع صفحات التلوين للنسخة المنفصلة.

قد تكون نسخة القصة جاهزة بينما نسخة التلوين ناقصة، لكن أرشفة المشروع الكامل في Drive لا تعتبر جاهزة إلا بعد اكتمالهما معًا.

## اختبار دورة الحياة

الأمر:

```bash
npm run test:book-lifecycle
```

الاختبار لا يتصل بـGemini أو Drive، ويغطي:

1. إدخال فكرة طفل.
2. إنتاج قصة أصلية من 8 مشاهد بواسطة مزود وهمي.
3. قبول فحص الأصالة.
4. موافقة ولي الأمر.
5. إنتاج 18 أصلًا بصريًا: بطل، غلاف، 8 صور قصة، و8 صفحات تلوين.
6. منع PDF قبل اعتماد الصور.
7. فتح نسختي PDF بعد اعتماد الصور.
8. إغلاق نسخة التلوين وDrive عند جعل صفحة تلوين واحدة غير إنتاجية.

## أوامر الجودة

```bash
npm run validate:system-readiness
npm run test:book-lifecycle
npm run quality:stories
```

## ما لم يُثبت بعد

- لم يُنفذ توليد قصة فعلي مدفوع.
- لم تُنتج صور فعلية من Gemini.
- لم يرفع خادم الموقع ملفًا فعليًا إلى Drive.
- لم تُراجع جودة كتاب حقيقي بصريًا.
- لم تظهر حالة CI مؤكدة على آخر commit عند كتابة هذا التقرير.

## شرط الانتقال إلى التجربة الحقيقية

تظهر لوحة الجاهزية الحالات التالية كجاهزة:

```text
توليد القصص: جاهز
توليد الصور: جاهز
Google Drive: جاهز
التشغيل الإنتاجي: جاهز
```

بعدها تُنشأ تجربة واحدة من 8 مشاهد فقط لتقليل التكلفة، ثم تُراجع القصة والصور ونسختا PDF وملفات Drive قبل الدمج في `main`.
