# ColorVerse Brand System

## Approved identity

The approved logo combines a colorful planet and orbiting crayons. The official wordmarks are `ColorVerse` and `عالم التلوين`.

## Typography

- English: Inter
- Arabic: Tajawal

## Core palette

| Token | Value |
|---|---|
| Orange | `#FF8A00` |
| Red | `#FF3D5A` |
| Purple | `#7C3AED` |
| Blue | `#159FEA` |
| Green | `#22C978` |
| Yellow | `#FFC928` |
| Navy | `#15224C` |
| Warm background | `#FFFAF4` |

## Direction and typography rules

Arabic content uses RTL and Tajawal. English content uses LTR and Inter. Headings remain compact, balanced, and readable. Numbers use tabular Latin numerals for dashboards and metrics.
