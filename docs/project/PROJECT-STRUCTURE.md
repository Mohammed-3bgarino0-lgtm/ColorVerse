# Project Structure

- `src/components`: application and marketing UI.
- `src/components/brand`: reusable brand primitives.
- `src/components/marketing`: landing-page sections.
- `src/lib/ai`: AI provider, validation, retry, and quality logic.
- `src/lib/firebase`: Firebase client and Admin integration.
- `src/lib/images`: image processing.
- `src/lib/payments`: payment adapters.
- `src/styles`: centralized visual tokens.
- `public/brand`: official logo exports.
- `docs/project`: brand and architecture notes.
- `docs/task-reports`: implementation and test reports.
