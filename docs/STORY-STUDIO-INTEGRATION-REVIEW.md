# مراجعة ربط استوديو القصة بالمراجع

الفرع: `feature/story-studio-integration`

## الهدف

ربط صفحة إنشاء القصة بكتالوج المراجع الحقيقي من دون نشر التغييرات أو تعديل الصفحة الأساسية قبل المراجعة.

## الملفات الجديدة

- `public/js/story-studio-runtime.js`
- `scripts/apply-story-studio-integration.mjs`
- `scripts/validate-story-studio-runtime.mjs`

## ما يضيفه ملف التشغيل

1. تحميل `public/data/story-references.json` ديناميكيًا.
2. تعبئة قائمة المراجع تلقائيًا بدل تثبيت قصة واحدة داخل الصفحة.
3. ترتيب المراجع حسب العمر واللغة والموضوع والقيمة والكلمات المرادفة.
4. اختيار موزون عشوائيًا من أفضل ثلاث نتائج.
5. تقليل تكرار المرجع المستخدم مؤخرًا.
6. عرض سبب المطابقة ودرجتها داخل خيار الاختيار الذكي.
7. استخراج أفكار الطفل التي يجب الحفاظ عليها.
8. توضيح الفرق بين إبداع الطفل وما أضافه المحرر.
9. إنشاء خطة مطابقة لعدد الصفحات: 8 أو 12 أو 16.
10. حفظ سياسة الأصالة داخل بيانات المسودة.

## حدود استخدام المرجع

المرجع يؤثر فقط على:

- البنية العامة.
- القيمة التربوية.
- مستوى القراءة.
- إيقاع التصاعد.

ولا يسمح بنسخ:

- النصوص.
- الأسماء.
- الأماكن.
- ترتيب المشاهد.
- الحوارات أو الرسومات.

## طريقة الدمج بعد الاعتماد

```bash
node scripts/apply-story-studio-integration.mjs create.html
```

الأداة لا تضيف ملف التشغيل مرتين، وتتوقف بخطأ واضح إذا لم تجد وسم `</body>`.

## فحص المرحلة

```bash
node --check public/js/story-studio-runtime.js
node scripts/validate-story-studio-runtime.mjs
```

## نقاط المراجعة اليدوية

1. اكتب قصة عن البخل واختر «اختيار ذكي»؛ يجب أن يظهر المرجع التربوي المناسب.
2. اكتب قصة بعيدة عن موضوعات الموسوعة؛ يجب أن يكمل النظام من فكرة الطفل دون فرض مرجع.
3. اختر 12 ثم 16 صفحة؛ يجب أن يتغير عدد عناصر خطة القصة.
4. تأكد من ظهور «أفكار الطفل المحفوظة» منفصلة عن «ما أضافه المحرر».
5. كرر الاختيار الذكي؛ يجب أن تنخفض أولوية المرجع المستخدم مؤخرًا عندما تتوفر مراجع متعددة.
